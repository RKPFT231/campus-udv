# Seguridad

DaCodex no tiene servidores ni guarda datos de nadie fuera de tu computador.

## Cómo reportar un fallo

Si encuentras una vulnerabilidad, **no la publiques**. Abre un *issue* con el título «Seguridad» sin detalles técnicos y se te dará un canal privado, o usa la opción *Report a vulnerability* de la pestaña Security de este repositorio.

## Cómo saber que tu copia es auténtica

- Descarga solo desde la sección **Releases** de este repositorio.
- Las actualizaciones automáticas llevan firma digital: la app rechaza cualquier actualización que no esté firmada por el autor.
